# Blue Raeven Farms — Website Editor Guide

A guide for editing the website in WordPress, no HTML required. Every section of every page is a **block** with simple fill-in fields.

## The basics

1. Log in to WordPress at `/wp-admin`.
2. Go to **Pages**, click the page you want to edit.
3. Click on any section of the page — its editable fields appear (text boxes, photo pickers, etc.).
4. Make your change, then click **Update** (top right). The change is live immediately.

**To preview before saving:** use the Preview button (top right) instead of Update.

### Editing photos
Any photo field shows the current photo with a pencil/X. Click it to choose a different photo from the **Media Library** or upload a new one. Photos should be sized appropriately before upload (the team can advise) — as a rule of thumb, 1200px wide for content photos, 1920px+ for full-width banners.

### Lists you can grow and shrink
Many blocks contain lists — pies, FAQs, retailers, timeline entries, photo slides. These show as rows with an **"Add …"** button at the bottom. Hover a row for options to **reorder (drag), duplicate, or delete** it.

## Things to know

- **The • separator**: product lists use the "•" character between items. Copy-paste it from existing text rather than typing a regular dash.
- **Script lines**: the handwritten-style text renders in the brand script font automatically — just type normal text.
- **Links**: for pages on this site, use the short form like `/farmstand/`. For other websites, paste the full address starting with `https://`.
- **Phone links**: in fields asking for "digits for dialing," enter only numbers, e.g. `5038350740`.
- **Undo**: every Update is saved as a revision — Pages → (the page) → Revisions restores any previous version.
- **Don't edit**: the form's access/captcha keys, and the Gallery ID field on mosaics, unless instructed.
